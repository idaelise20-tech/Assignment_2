# Rana FK – Men's Team

A student project for Individual Assignment 2 in Full-Stack Development.

The website presents 18 Rana FK players in a responsive card layout.
Each card includes a player image, name, shirt number, position and birth year.

## Technologies

- HTML5
- CSS3
- CSS Grid
- Media queries
- CSS variables
- BEM naming convention
